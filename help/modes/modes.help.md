<!-- TOPIC: mode:browse -->
<!-- TITLE: Browse Mode -->

## Description

Browse mode is read-only viewing. You can navigate, search, and scroll, but edits
are not permitted.

## Entering / Leaving

- Open a file for viewing, or use the browse action.
- Switch to [Edit mode](mode:edit) to make changes.

## See Also

- [Edit mode](mode:edit), [View mode](mode:view)

<!-- TOPIC: mode:edit -->
<!-- TITLE: Edit Mode -->

## Description

Edit mode allows full modification of the file: typing, line commands, and
transactions with [undo/redo](feature:undo).

## See Also

- [Browse mode](mode:browse), [Line commands](line:index)

<!-- TOPIC: mode:view -->
<!-- TITLE: View Mode -->

## Description

View mode is a protected view similar to Browse, allowing scrolling and search
without saving changes back to the file.

## See Also

- [Browse mode](mode:browse), [Edit mode](mode:edit)

<!-- TOPIC: mode:hex -->
<!-- TITLE: Hex Mode -->

## Description

Hex mode shows the byte values of the file alongside the character view, for
inspecting binary or encoding details.

## Entering / Leaving

- Toggle with the [HEX](cmd:HEX) command.

## See Also

- [HEX command](cmd:HEX)

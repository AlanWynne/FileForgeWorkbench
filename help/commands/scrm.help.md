<!-- TOPIC: cmd:SCRM -->
<!-- TITLE: SCRM Command -->

## Syntax

```
SCRM
```

## Description

Opens the Screen Capture and Recording menu, from which you can snapshot the
screen, start or stop a capture session, and replay a saved session.

## See Also

- [SNAPSHOT](cmd:SNAPSHOT), [CAPTURE](cmd:CAPTURE), [RETRIEVE](cmd:RETRIEVE)

<!-- TOPIC: cmd:SNAPSHOT -->
<!-- TITLE: SNAPSHOT Command -->

## Syntax

```
SNAPSHOT
```

## Description

Copies the current screen to the clipboard as logical text, capturing the
rendered Workspace as a composite the clipboard can paste.

## See Also

- [CAPTURE](cmd:CAPTURE), [RETRIEVE](cmd:RETRIEVE), [SCRM](cmd:SCRM)

<!-- TOPIC: cmd:CAPTURE -->
<!-- TITLE: CAPTURE Command -->

## Syntax

```
CAPTURE START | STOP | REPLAY
```

## Description

Records a capture session. START begins recording, STOP saves the session, and
REPLAY opens a saved session for playback.

## See Also

- [SNAPSHOT](cmd:SNAPSHOT), [RETRIEVE](cmd:RETRIEVE), [SCRM](cmd:SCRM)

<!-- TOPIC: cmd:RETRIEVE -->
<!-- TITLE: RETRIEVE Command -->

## Syntax

```
RETRIEVE
```

## Description

Retrieves a previously captured screen or session for review from the capture
store.

## See Also

- [CAPTURE](cmd:CAPTURE), [SNAPSHOT](cmd:SNAPSHOT), [SCRM](cmd:SCRM)

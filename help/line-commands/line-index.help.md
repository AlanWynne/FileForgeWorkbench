# Line Commands

Line commands are typed in the prefix area (the number column) to the left of a
line, then applied on Enter. Doubling a letter marks a block (for example `DD`
... `DD` deletes a range).

| Command | Action |
|---------|--------|
| `D` / `DD` | Delete a line / a block |
| `I` | Insert a new line below |
| `R` / `RR` | Repeat a line / a block |
| `C` / `CC` | Copy a line / a block (needs an A or B target) |
| `M` / `MM` | Move a line / a block (needs an A or B target) |
| `A` / `B` | Destination After / Before (target for C and M) |
| `X` / `XX` | Exclude (hide) a line / a block |
| `T` / `TT` | Text-split markers |
| `U` / `UU` | Uppercase / block |
| `>` / `>>` | Shift right a line / a block |
| `<` / `<<` | Shift left a line / a block |
| `)` / `))` | Shift-data right |
| `(` / `((` | Shift-data left |
| `COLS` | Show a column ruler |
| `BNDS` | Show / set the bounds ruler |
| `TABS` | Show / set tab stops |
| `MASK` | Edit the insert mask |
